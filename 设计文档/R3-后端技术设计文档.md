## 四、关键业务流程

### 4.1 出库单状态机

```
DRAFT ──分配库存──▶ ALLOCATED ──生成拣货任务──▶ PICKING ──拣货完成──▶ PICKED
                                                          │
   CANCELLED（终态）◀──任意状态──┘                   PACKING ──打包完成──▶ SHIPPED
```

**状态校验**（`OutboundStatus` 枚举 + `canTransition`）：
- DRAFT：可编辑、可取消
- ALLOCATED：已锁定库存，可生成波次/拣货、可取消（释放锁定）
- PICKING：拣货中
- PICKED：拣货完成，进入复核打包
- PACKING：打包中
- SHIPPED / CANCELLED：终态

### 4.2 库存锁定与扣减（跨服务事务）

```
wms-outbound 分配库存(allocate) / 波次生成(generate)
   1. 校验出库单为 DRAFT
   2. 逐明细调用 wms-inventory Feign: lock(skuId, locationId, batchNo, planQty, relatedNo)
   3. 失败后回滚并提示 OUTBOUND_STOCK_LOCK_FAIL(24004)
   4. 出库单置 ALLOCATED

wms-outbound 发货(ship)
   1. 校验出库单为 PACKING
   2. 逐明细先 unlock(planQty) 释放预留，再 decrease(shipQty) 扣减实物
      （shipQty = 已拣数量 > 0 ? 已拣 : 计划）
   3. 失败回滚并提示 OUTBOUND_STOCK_DECREASE_FAIL(24005)
   4. 出库单置 SHIPPED，生成 shipping_record(LOADED)
```

**一致性策略**：最终一致。出库为主，库存锁定/扣减失败则回滚 outbound 事务并提示。

### 4.3 拣货回写

```
wms-outbound 拣货确认(confirmPick)
   1. 校验任务 PENDING 且实际数量 ≤ 待拣数量（超额 24006）
   2. 回写 pick_task.actual_qty=PICKED、outbound_item.picked_qty
   3. 该出库单全部任务 PICKED → 订单 PICKING→PICKED
```

## 五、出库核心 API（wms-outbound）

| 接口 | HTTP | 路径 | 说明 |
|---|---|---|---|
| 创建出库单 | POST | `/api/v1/outbound/orders` | 订单接入（草稿） |
| 分配库存 | PUT | `/api/v1/outbound/orders/{id}/allocate` | DRAFT→ALLOCATED（锁库存） |
| 取消 | PUT | `/api/v1/outbound/orders/{id}/cancel` | 释放锁定并置 CANCELLED |
| 创建波次 | POST | `/api/v1/outbound/waves` | PENDING |
| 生成波次 | POST | `/api/v1/outbound/waves/generate` | 纳入出库单并锁库存 |
| 生成拣货任务 | POST | `/api/v1/outbound/pick/tasks` | 按 waveId |
| 拣货确认 | PUT | `/api/v1/outbound/pick/confirm` | 回写已拣 |
| 复核打包 | POST | `/api/v1/outbound/pack` | PICKED→PACKING |
| 装车发货 | POST | `/api/v1/outbound/ship` | 扣库存→SHIPPED |

**依赖的库存内部接口**（来自 `wms-api-inventory`）：`StockFeignClient.lock` / `unlock` / `decrease`。

## 六、错误码

| 错误码 | 常量 | 说明 |
|---|---|---|
| 24001 | OUTBOUND_NO_EXISTS | 出库单号已存在 |
| 24002 | OUTBOUND_NOT_FOUND | 出库单不存在 |
| 24003 | OUTBOUND_STATUS_INVALID | 出库单状态不允许该操作 |
| 24004 | OUTBOUND_STOCK_LOCK_FAIL | 库存锁定失败，可用库存不足 |
| 24005 | OUTBOUND_STOCK_DECREASE_FAIL | 库存扣减失败，可用库存不足 |
| 24006 | OUTBOUND_QTY_EXCEED | 拣货/打包数量超过待处理数量 |
| 24007 | WAVE_NOT_FOUND | 波次不存在 |
| 24008 | WAVE_STATUS_INVALID | 波次状态不允许该操作 |
| 24009 | PICK_TASK_NOT_FOUND | 拣货任务不存在 |

## 七、技术选型与复用

- 统一响应 / 异常 / 鉴权：复用 `wms-common-*`（R1 已落地）
- 库存锁定/扣减：复用 R2 的 `StockFeignClient`（lock/unlock/decrease）+ 乐观锁流水
- 操作日志：`@OperationLog`（wms-common-log）
- 逻辑删除：`deleted` 字段，取值判空防 NPE（已做 null-safe 处理）
