### 1.1 系统框架搭建

#### 1.1.1 用户登录

**功能描述**：

系统统一入口，支持用户名 + 密码登录，登录成功后进入主控台。

**业务规则**：

1. 用户名 + 密码校验，密码加密存储（MD5/SHA-256 + 盐值）
2. 密码长度 ≥ 8 位
3. 连续输错 5 次密码，锁定账户 30 分钟
4. 登录成功记录最后登录时间
5. 支持记住密码（可选）

**输入**：

- 用户名
- 密码

**输出**：

- 登录成功 → 跳转主控台
- 登录失败 → 提示错误信息

**用户故事**：

> 作为**系统管理员**，我希望使用用户名密码登录系统，以便进入系统进行管理操作。

**异常场景**：

| 异常 | 处理 |
|---|---|
| 用户名不存在 | 提示"用户名不存在" |
| 密码错误 | 提示"密码错误，剩余 X 次尝试机会" |
| 账户已停用 | 提示"账户已停用，请联系管理员" |
| 账户已锁定 | 提示"账户已锁定，请 30 分钟后重试" |

**验收标准**：

- [ ] 用户名密码登录成功
- [ ] 密码错误 5 次后锁定
- [ ] 停用账户无法登录

---

#### 1.1.2 主控台框架

**功能描述**：

系统主界面框架，包含顶部导航栏、左侧菜单栏、右侧内容区。

**业务规则**：

1. 顶部：系统名称、当前仓库（多仓切换）、当前用户、消息通知、退出登录
2. 左侧：按角色动态渲染的菜单树
3. 右侧：内容展示区

**用户故事**：

> 作为**系统用户**，我希望进入系统后看到清晰的导航结构，以便快速找到需要的功能。

**验收标准**：

- [ ] 顶部显示系统名称、当前用户
- [ ] 左侧菜单按角色权限动态展示

---

#### 1.1.3 菜单与权限路由

**功能描述**：

基于 RBAC 权限体系，动态渲染用户可见的菜单项。

**业务规则**：

1. 菜单与功能权限关联
2. 用户登录后获取角色对应的菜单权限
3. 无权限访问时跳转 403 页面

**验收标准**：

- [ ] 不同角色登录看到不同的菜单
- [ ] 无权限访问提示 403

统一的前端异常展示与后端错误码映射。

**业务规则**：

1. 网络异常：提示"网络连接失败，请检查网络"

**业务规则**：

**输入**：

**输出**：

**验收标准**：

- [ ] 登录操作被记录

### 1.2 用户与权限管理

#### 1.2.1 用户管理（CRUD）

**功能描述**：

管理系统用户账户，支持创建、查询、修改、启用/停用。

**业务规则**：

1. 用户必填字段：用户名、姓名、角色、所属仓库（部分角色）、手机号
2. 用户名全局唯一
3. 初始密码默认 123456，首次登录强制修改
4. 停用后无法登录，历史数据保留

**输入**：

- 用户名、姓名、角色、所属仓库、手机号、邮箱

**输出**：

- 用户列表（分页）
- 用户详情

**用户故事**：

> 作为**系统管理员**，我希望能够创建用户并分配角色，以便仓库人员可以登录系统。

**异常场景**：

| 异常 | 处理 |
|---|---|
| 用户名重复 | 提示"用户名已存在" |
| 必填字段为空 | 提示具体哪个字段必填 |
| 停用有未完成任务的用户 | 允许停用，任务自动释放 |

**验收标准**：

- [ ] 可创建用户
- [ ] 可修改用户信息
- [ ] 可启用/停用用户
- [ ] 停用后无法登录

### 1.3 SKU 主数据管理

#### 1.3.1 SKU 创建

**功能描述**：

创建 SKU 主数据，是整个系统的核心基础数据。

**业务规则**：

1. SKU 由 `SPU + 颜色 + 尺码` 唯一确定
2. SKU 编码全局唯一，支持手动或自动生成
3. 条形码支持一品多码（多包装规格对应不同条码）
4. 必填字段：SKU 编码、商品名称、SPU、颜色、尺码
5. 选填字段：重量、体积、长宽高、图片、保质期、类目
6. 创建后默认状态为"启用"

**输入**：

- SKU 编码（系统自动生成或手动）
- SPU 编码
- 商品名称
- 颜色、尺码
- 条形码（可多个）
- 重量、体积、规格
- 商品图片
- 保质期（天）
- 类目

**输出**：

- 创建结果

**用户故事**：

> 作为**系统管理员**，我希望能够创建 SKU 主数据，以便后续出入库使用。

**异常场景**：

| 异常 | 处理 |
|---|---|
| SKU 编码重复 | 提示"SKU 编码已存在，请重新输入" |
| 条形码已存在 | 提示"该条形码已被其他 SKU 占用" |
| 必填字段为空 | 提示具体哪个字段必填 |

**验收标准**：

- [ ] 可创建单个 SKU，必填字段校验生效
- [ ] SKU 编码唯一性校验生效

---

支持 Excel 批量导入 SKU 数据。

3. 导入失败返回错误明细 Excel

**输入**：

- Excel 文件

**输出**：

- 导入成功数量
- 失败明细

**用户故事**：

> 作为**系统管理员**，我希望能够批量导入和导出 SKU 数据，以便快速初始化系统或与其他系统对接。

**验收标准**：

- [ ] 可批量导入 SKU（Excel 模板）
- [ ] 导入错误提示明确

#### 1.3.3 SKU 批量导出

**功能描述**：

支持 Excel 批量导出 SKU 数据。

#### 1.3.4 SKU 查询与列表

**功能描述**：

多维度查询 SKU 列表。

**业务规则**：

1. 查询条件：SKU 编码、商品名称、条形码、类目、状态
2. 支持分页
3. 支持按状态筛选（启用/停用）

---

#### 1.3.5 SKU 编辑与停用

**功能描述**：

修改 SKU 信息或停用 SKU。

**业务规则**：

**输出**：

- 修改结果

| 异常 | 处理 |

| 删除有库存的 SKU | 提示"该 SKU 存在库存，无法删除，请先停用" |

- [ ] 停用 SKU 后无法在出入库页面检索到

### 1.5 库位主数据管理

#### 1.5.1 库位创建（单个）

**功能描述**：

管理仓库内的库位信息，库位是商品存放的物理位置。

**业务规则**：

1. 库位编码规则：`{仓库编码}-{区域}-{货架}-{层}-{列}-{位}`
   - 例：`WH-001-A-03-02-05`
2. 库位类型：
   - 普通库位（常规存放）
   - 暂存库位（出入库中转）
   - 不良品库位（存放不合格商品）
   - 退货待检库位（待质检的退货）
3. 库位状态：空闲 / 占用 / 锁定 / 维修中
4. 库位可设置最大承重（kg）、最大体积（m³）

**输入**：

- 库位编码、所属仓库、所属区域、货架号、层号、列号、位号
- 库位类型、最大承重、最大体积

**输出**：

- 创建结果

**用户故事**：

> 作为**系统管理员**，我希望能够管理库位信息，以便商品上架有位置可存。

**异常场景**：

| 异常 | 处理 |
|---|---|
| 库位编码重复 | 提示"库位编码已存在" |

**验收标准**：

### 1.6 供应商基础数据

#### 1.6.1 供应商创建

**功能描述**：

管理供应商信息，为 R2 入库预约提供供应商选择。

**业务规则**：

1. 供应商编码唯一
2. 必填：供应商编码、名称、联系人、电话
3. 选填：地址、备注

**输入**：

- 供应商编码、名称、联系人、电话、地址

**输出**：

- 创建结果

**验收标准**：

- [ ] 可创建供应商

---

#### 1.6.2 供应商列表与查询

**功能描述**：

供应商列表展示与查询。

**业务规则**：

1. 支持按编码、名称模糊搜索
2. 支持按状态筛选

**输出**：

- 供应商列表

**验收标准**：

- [ ] 可查询供应商

---

#### 1.6.3 供应商停用

**功能描述**：

停用供应商。

**业务规则**：

1. 停用后不可在入库预约中选择
2. 历史数据保留

**验收标准**：

- [ ] 停用后不可被选择

### 1.7 基础数据字典/配置中心

#### 1.7.1 枚举字典管理

**功能描述**：

管理系统状态枚举值。

**业务规则**：

1. 预置枚举：库位类型、仓库类型、入库类型、出库单状态等
2. 枚举不可删除，可禁用

**验收标准**：

- [ ] 系统枚举预置完整

---

#### 1.7.2 编码规则配置

**功能描述**：

配置单据编码规则。

**业务规则**：

1. 编码组成：前缀 + 日期 + 流水号
2. 可配置：前缀、日期格式、流水号位数

**验收标准**：

- [ ] 可配置编码规则

---

#### 1.7.3 系统参数配置

**功能描述**：

系统级业务参数配置。

**业务规则**：

1. 参数示例：密码最小长度、登录失败锁定次数、库存预警默认阈值
2. 参数修改记录审计日志

**验收标准**：

- [ ] 可配置系统参数
