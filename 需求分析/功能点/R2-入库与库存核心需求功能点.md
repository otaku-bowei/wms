## 二、模块 2：入库管理

### 2.1 入库预约单

**功能描述**：

供应商发货前，库管员创建入库预约单，记录预计到货信息，便于仓库提前安排收货资源。

**业务规则**：

1. 入库类型：采购入库（PURCHASE）/ 退货入库（RETURN）/ 调拨入库（TRANSFER）
2. 预约单必填：仓库、入库类型、供应商、预计到货时间、SKU 明细
3. 预约单生成后可修改，到达后（ARRIVED 及之后状态）不可修改
4. 状态：草稿（DRAFT）→ 已确认（CONFIRMED）→ 已到货（ARRIVED）→ 待质检（PENDING_QC）→ 上架中（PUTTING_AWAY）→ 已完成（COMPLETED），任一状态可取消（CANCELLED）
5. 入库单号按编码规则生成（前缀 IN + yyyyMMdd + 3 位流水）
6. 明细至少包含 1 个 SKU，计划数量 > 0

**输入**：

- 仓库 ID、入库类型、供应商 ID、预计到货时间、备注
- 商品明细：SKU ID、计划数量、批次号

**输出**：

- 入库单列表（分页）、入库单详情（含明细）、创建/修改结果、状态变更结果

**用户故事**：

> 作为**仓库管理员**，我希望提前创建入库预约单，以便合理安排仓库收货资源。

> 作为**库管主管**，我希望看到所有待到货的入库预约，以便跟踪供应商发货情况。

**异常场景**：

| 异常 | 处理 |
|---|---|
| 明细为空 | 提示"入库明细不能为空" |
| 计划数量 ≤ 0 | 提示"计划数量必须大于 0" |
| 仓库已停用 | 提示"仓库已停用，无法创建入库单" |
| 已到货后修改 | 提示"已到货单据不可修改" |
| 重复取消 | 提示"该单据已取消" |

**验收标准**：

- [ ] 可创建采购/退货/调拨三种入库单
- [ ] 明细为空或数量非法时拒绝提交
- [ ] 仓库停用时拒绝创建
- [ ] 草稿可改可删，确认后不可删
- [ ] 已到货单据不可修改
- [ ] 取消后不可再做任何操作
- [ ] 单号按 IN+日期+流水自动生成

### 2.2 到货验收

**功能描述**：

货物到达仓库后，仓库管理员使用 PDA 扫码验收，确认实际到货数量、批次、效期等信息。

**业务规则**：

1. 必须按预约单验收（无预约单的可手工创建）
2. PDA 扫码条码自动识别 SKU
3. 实收数量与计划数量不一致时，系统给出提示但允许继续
4. 验收时录入批次号、效期（食品/化妆品必填）
5. 验收完成后状态变为"待质检"

**用户故事**：

> 作为**仓库管理员**，我希望用 PDA 扫码验收，能自动识别 SKU 和批次，以便提高验收效率。

> 作为**仓库管理员**，我希望能够处理多货少货情况，并自动记录差异。

**异常场景**：

| 异常 | 处理 |
|---|---|
| 条码未识别 | 提示"未知条码"并允许手工输入 SKU |
| 扫到非本单 SKU | 提示"该 SKU 不在入库单明细中" |
| 单据状态非已确认 | 拒绝验收 |

### 2.3 质检流程

**业务规则**：

1. 质检结果：合格 / 不合格
2. 不合格商品可选：拒收（退回供应商）/ 入不良品库位
3. 合格商品进入"上架"
4. 质检需录入质检人、质检时间、质检结果
5. 支持部分合格（如 100 件中 95 合格、5 不合格）

### 2.4 智能库位分配

**业务规则**：

1. 推荐策略：周转率优先、体积匹配、承重匹配、FEFO 临期优先、同类集中
2. 推荐结果给出 Top 3 候选，库管员可调整
3. 一键应用推荐或手动指定库位

### 2.5 上架确认

**业务规则**：

1. PDA 扫码确认上架（扫 SKU + 扫库位）
2. 上架数量不可超过待上架数量
3. 上架完成后库存变为可售状态
4. 支持一单多次上架（分批上架到不同库位）

## 三、模块 4：库存管理

### 4.1 库存查询

**业务规则**：

1. 查询维度：仓库+SKU、库位+SKU、SKU+批次、按状态（可用/锁定/冻结）
2. 查询结果可导出 Excel
3. 支持快速定位库存（输入 SKU 编码）

### 4.2 库存调整

**业务规则**：

1. 调整原因：盘点差异、报损、报溢、其他
2. 调整需审批：库管主管审批后才能修改库存
3. 调整记录全部留痕，可追溯
4. 调整后系统自动记录库存流水

### 4.3 库存预警

**业务规则**：

1. 预警类型：低库存、高库存、临期、呆滞
2. 预警方式：站内消息、邮件、短信（可配置）
3. 预警可启用 / 停用

### 4.4 库存流水

**业务规则**：

1. 流水类型：入库、出库、调整、锁定、解锁
2. 流水字段：时间、SKU、库位、变动数量、操作人、关联单据
3. 流水不可修改、不可删除（只可作废）

## 四、关键状态机

### 4.1 入库单状态流转

```
DRAFT ──确认──▶ CONFIRMED ──到货──▶ ARRIVED ──提交质检──▶ PENDING_QC
                                                            │
                       COMPLETED ◀──完成── PUTTING_AWAY ◀──────┘
                                          （质检通过后才可上架）
  任意状态 ──取消──▶ CANCELLED（终态）
```

**状态校验规则**：
- `DRAFT` 可编辑、可删除
- `CONFIRMED` 可到货、可取消，不可删除
- `ARRIVED` 必须提交质检，不可修改明细
- `PENDING_QC` 质检通过后进入 `PUTTING_AWAY`
- `PUTTING_AWAY` 上架完成后进入 `COMPLETED`
- `CANCELLED` / `COMPLETED` 为终态，不可再做任何操作
