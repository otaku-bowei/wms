## 二、ER 关系

```
【入库域】

┌──────────────────┐        ┌──────────────────┐
│  inbound_order   │ 1 ── n │  inbound_item    │
│  入库预约单       │        │  入库明细         │
└────────┬─────────┘        └────────┬─────────┘
         │                              │
         │ warehouse_id                  │ sku_id
         ▼                              ▼
   base_warehouse               base_sku

┌──────────────────┐
│  inbound_item   │ 1 ── n │ inbound_qc │
└─────────────────┘        └─────────────┘

┌──────────────────┐
│  inbound_item    │ 1 ── n │ putaway_task │
└─────────────────┘        └───────────────┘

【库存域】

┌──────────────────┐
│   inv_stock      │ n ── 1 │ inv_transaction │
└─────────────────┘        └──────────────────┘
   （每次库存变动生成一条流水）

┌──────────────────┐
│inv_warning_rule  │ 1 ── n │ inv_warning_record │
└─────────────────┘          └──────────────────┘
```

## 三、入库域表设计

### 3.1 inbound_order 入库预约单

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| inbound_no | VARCHAR(32) | 否 | - | 入库单号（唯一，IN+日期+流水） |
| warehouse_id | BIGINT UNSIGNED | 否 | - | 仓库 ID |
| inbound_type | VARCHAR(20) | 否 | PURCHASE | PURCHASE / RETURN / TRANSFER |
| supplier_id | BIGINT UNSIGNED | 是 | NULL | 供应商 ID（调拨入库可空） |
| expected_time | DATETIME | 是 | NULL | 预计到货时间 |
| arrive_time | DATETIME | 是 | NULL | 实际到货时间 |
| status | VARCHAR(20) | 否 | DRAFT | DRAFT/CONFIRMED/ARRIVED/PENDING_QC/PUTTING_AWAY/COMPLETED/CANCELLED |
| remark | VARCHAR(500) | 是 | NULL | 备注 |
| create_by | VARCHAR(50) | 是 | NULL | 创建人 |
| create_time | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| update_by | VARCHAR(50) | 是 | NULL | 修改人 |
| update_time | DATETIME | 否 | CURRENT_TIMESTAMP | 修改时间 |
| deleted | TINYINT | 否 | 0 | 逻辑删除 |

**索引**：

| 索引 | 字段 | 类型 |
|---|---|---|
| PRIMARY | id | 主键 |
| uk_inbound_no | inbound_no | 唯一 |
| idx_warehouse_id | warehouse_id | 普通 |
| idx_supplier_id | supplier_id | 普通 |
| idx_status | status | 普通 |
| idx_expected_time | expected_time | 普通 |

### 3.2 inbound_item 入库明细

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| inbound_id | BIGINT UNSIGNED | 否 | - | 入库单 ID |
| sku_id | BIGINT UNSIGNED | 否 | - | SKU ID |
| plan_qty | INT | 否 | 0 | 计划数量 |
| received_qty | INT | 否 | 0 | 实收数量 |
| qualified_qty | INT | 否 | 0 | 合格数量 |
| defect_qty | INT | 否 | 0 | 不合格数量 |
| putaway_qty | INT | 否 | 0 | 已上架数量 |
| batch_no | VARCHAR(50) | 是 | NULL | 批次号 |
| production_date | DATE | 是 | NULL | 生产日期 |
| expiry_date | DATE | 是 | NULL | 到期日期 |
| create_time / update_time / deleted | - | - | 审计字段 |

**索引**：`idx_inbound_id`、`idx_sku_id`、`idx_batch_no`

## 四、库存域表设计

### 4.1 inv_stock 库存

| 字段 | 类型 | 空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT UNSIGNED | 否 | 自增 | 主键 |
| sku_id | BIGINT UNSIGNED | 否 | - | SKU ID |
| warehouse_id | BIGINT UNSIGNED | 否 | - | 仓库 ID |
| location_id | BIGINT UNSIGNED | 否 | - | 库位 ID |
| batch_no | VARCHAR(50) | 是 | NULL | 批次号 |
| production_date | DATE | 是 | NULL | 生产日期 |
| expiry_date | DATE | 是 | NULL | 到期日期 |
| total_qty | INT | 否 | 0 | 总库存 |
| available_qty | INT | 否 | 0 | 可用库存 |
| locked_qty | INT | 否 | 0 | 锁定库存 |
| frozen_qty | INT | 否 | 0 | 冻结库存 |
| status | VARCHAR(20) | 否 | NORMAL | NORMAL / FROZEN |
| create_time / update_time / deleted | - | - | 审计字段 |

**唯一约束**：`uk_stock` = (sku_id, warehouse_id, location_id, batch_no, deleted) —— 防止同一库位同批次重复记录

### 4.2 inv_transaction 库存流水

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT UNSIGNED | 主键 |
| transaction_no | VARCHAR(32) | 流水号（唯一） |
| sku_id | BIGINT UNSIGNED | SKU ID |
| warehouse_id | BIGINT UNSIGNED | 仓库 |
| location_id | BIGINT UNSIGNED | 库位 |
| batch_no | VARCHAR(50) | 批次号 |
| transaction_type | VARCHAR(20) | INBOUND / OUTBOUND / ADJUST / LOCK / UNLOCK / FREEZE |
| quantity | INT | 变动数量（正为增加，负为减少） |
| before_qty | INT | 变动前可用库存 |
| after_qty | INT | 变动后可用库存 |
| related_no | VARCHAR(64) | 关联单号 |
| operator | VARCHAR(50) | 操作人 |
| operate_time | DATETIME | 操作时间 |

**说明**：流水不可修改、不可删除（只可作废）。

### 4.3 inv_adjust / inv_adjust_item

调整单主表与明细，支持审批流（草稿 → 待审批 → 已通过 / 已驳回）。

### 4.4 inv_warning_rule / inv_warning_record

预警规则配置与触发记录。
