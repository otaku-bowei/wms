## 一、通用约定

### 1.1 基础信息

| 项 | 说明 |
|---|---|
| 协议 | HTTP / HTTPS |
| 基础路径 | `https://{host}/api/v1` |
| 请求方式 | GET / POST / PUT / DELETE |
| 请求编码 | UTF-8 |
| 数据格式 | `application/json` |
| 文件上传 | `multipart/form-data` |

### 1.2 认证方式

除登录接口外，所有接口需在 Header 中携带 Token：

```
Authorization: Bearer {token}
```

- Token 由 `/auth/login` 返回，有效期 8 小时
- Token 失效返回 `401`，前端跳转登录页

### 1.3 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": 1759824000000,
  "traceId": "a1b2c3d4e5f6"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0=成功，非 0=失败 |
| message | string | 提示信息 |
| data | object | 业务数据 |
| timestamp | long | 响应时间戳（毫秒） |
| traceId | string | 链路追踪 ID |

### 1.4 分页规范

**请求参数**：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| pageNum | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 20 | 每页条数，最大 100 |

**响应结构**：

```json
{
  "code": 0,
  "data": {
    "list": [],
    "total": 12345,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 618
  }
}
```

### 1.5 错误码

**通用错误码**：

| code | HTTP | 说明 |
|---|---|---|
| 0 | 200 | 成功 |
| 400 | 400 | 请求参数错误 |
| 401 | 401 | 未认证 / Token 失效 |
| 403 | 403 | 无权限访问 |
| 404 | 404 | 资源不存在 |
| 405 | 405 | 请求方法不支持 |
| 500 | 500 | 系统内部错误 |

**业务错误码**：

| code | 说明 |
|---|---|
| 10001 | 用户名或密码错误 |
| 10002 | 账户已停用 |
| 10003 | 账户已锁定，请 30 分钟后重试 |
| 10004 | 用户名已存在 |
| 10005 | 原密码错误 |
| 10006 | 密码长度不能少于 8 位 |
| 10007 | 密码需包含字母和数字 |
| 20001 | SKU 编码已存在 |
| 20002 | 该条形码已被其他 SKU 占用 |
| 20003 | 该 SKU 存在库存，无法删除，请先停用 |
| 20004 | 必填字段不能为空 |
| 20005 | SKU 导入模板格式错误 |
| 30001 | 仓库编码已存在 |
| 30002 | 仓库已停用，无法创建出入库单 |
| 30003 | 区域编码已存在 |
| 40001 | 库位编码已存在 |
| 40002 | 库位已被占用 |
| 40003 | 库位处于锁定/维修中，不可用于上架 |
| 40004 | 批量创建数量超出限制（单次 ≤ 5000） |
| 50001 | 供应商编码已存在 |
| 50002 | 供应商已停用 |

## 三、认证与鉴权

### 3.1 用户登录

```
POST /auth/login
```

**是否需要认证**：否

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码（明文传输，HTTPS 加密） |
| rememberMe | boolean | 否 | 记住密码，默认 false |

**请求示例**：

```json
{
  "username": "admin",
  "password": "Admin@123",
  "rememberMe": false
}
```

**响应 data**：

| 字段 | 类型 | 说明 |
|---|---|---|
| token | string | JWT Token |
| expiresIn | long | 有效期（秒） |
| userId | long | 用户 ID |
| username | string | 用户名 |
| realName | string | 姓名 |
| roleCode | string | 角色编码 |
| warehouseId | long | 所属仓库 ID（可空） |
| warehouseName | string | 所属仓库名称 |
| forceChangePassword | boolean | 是否强制修改密码（首次登录） |

**响应示例**：

```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 28800,
    "userId": 1,
    "username": "admin",
    "realName": "张三",
    "roleCode": "SYSTEM_ADMIN",
    "warehouseId": null,
    "warehouseName": null,
    "forceChangePassword": false
  }
}
```

**错误码**：10001、10002、10003

---

### 3.2 退出登录

```
POST /auth/logout
```

**请求参数**：无（Token 从 Header 解析）

**响应 data**：`null`

**说明**：退出后 Token 加入黑名单，立即失效。

---

### 3.3 修改密码

```
POST /auth/password
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| oldPassword | string | 是 | 原密码 |
| newPassword | string | 是 | 新密码（≥8 位，含字母+数字） |
| confirmPassword | string | 是 | 确认新密码 |

**响应 data**：`null`

**错误码**：10005、10006、10007

---

### 3.4 获取当前用户信息

```
GET /auth/current
```

**响应 data**：同登录接口 `data` 结构（不含 token）

---

### 3.5 获取用户菜单

```
GET /auth/menus
```

**响应 data**：

```json
{
  "menus": [
    {
      "id": 1,
      "parentId": 0,
      "name": "基础数据",
      "path": "/basic",
      "icon": "database",
      "sort": 1,
      "children": [
        {
          "id": 11,
          "parentId": 1,
          "name": "SKU 管理",
          "path": "/basic/sku",
          "icon": "goods",
          "sort": 1,
          "children": []
        }
      ]
    }
  ],
  "permissions": [
    "sku:view",
    "sku:create",
    "sku:edit",
    "sku:import"
  ]
}
```

**说明**：`permissions` 为按钮级权限标识，供前端控制按钮显隐。

---

### 3.6 刷新 Token

```
POST /auth/refresh
```

**请求参数**：无（旧 Token 从 Header 解析）

**响应 data**：

| 字段 | 类型 | 说明 |
|---|---|---|
| token | string | 新 Token |
| expiresIn | long | 有效期（秒） |

### 4.2 创建用户

```
POST /users
```

**权限**：`user:create`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名（唯一，4-20 位字母数字） |
| realName | string | 是 | 姓名 |
| roleCode | string | 是 | 角色编码 |
| warehouseId | long | 否 | 所属仓库 ID（部分角色必填） |
| phone | string | 是 | 手机号 |
| email | string | 否 | 邮箱 |
| status | int | 否 | 状态，默认 1 启用 |

**请求示例**：

```json
{
  "username": "picker01",
  "realName": "王五",
  "roleCode": "PICKER",
  "warehouseId": 1,
  "phone": "13800138002",
  "email": "picker01@wms.com",
  "status": 1
}
```

**响应 data**：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | 用户 ID |
| defaultPassword | string | 系统生成的初始密码（仅创建时返回一次） |

**错误码**：10004、20004

**业务说明**：初始密码默认 `123456`，该用户首次登录强制修改密码（`forceChangePassword=true`）。


---

### 4.5 启用/停用用户

```
PUT /users/{id}/status
```

**权限**：`user:edit`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| status | int | 是 | 1 启用 / 0 停用 |

**响应 data**：`null`

**业务说明**：停用后该用户无法登录，其未完成任务自动释放。

---

### 4.6 重置密码

```
POST /users/{id}/reset-password
```

**权限**：`user:edit`（系统管理员）

**响应 data**：

| 字段 | 类型 | 说明 |
|---|---|---|
| newPassword | string | 重置后的密码 |

**业务说明**：重置为 `123456`，用户下次登录强制修改。

---

### 4.7 校验用户名是否可用

```
GET /users/check-username?username={username}
```

**响应 data**：

```json
{
```

### 7.2 创建 SKU

```
POST /skus
```

**权限**：`sku:create`（系统管理员）

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| skuCode | string | 否 | SKU 编码（不传则系统按规则自动生成） |
| spuCode | string | 是 | SPU 编码 |
| skuName | string | 是 | 商品名称 |
| color | string | 是 | 颜色 |
| size | string | 是 | 尺码 |
| categoryId | long | 否 | 类目 ID |
| barcodes | array[string] | 是 | 条形码（≥1 个，支持一品多码） |
| weight | decimal | 否 | 重量（克） |
| volume | decimal | 否 | 体积（毫升） |
| length | int | 否 | 长（mm） |
| width | int | 否 | 宽（mm） |
| height | int | 否 | 高（mm） |
| imageUrl | string | 否 | 商品图片 URL |
| shelfLifeDays | int | 否 | 保质期（天），食品/化妆品常用 |

**请求示例**：

```json
{
  "spuCode": "SP001",
  "skuName": "夏季连衣裙",
  "color": "红色",
  "size": "S",
  "categoryId": 10,
  "barcodes": ["6901234567890", "6901234567891"],
  "weight": 200.00,
  "volume": 500.00,
  "length": 300,
  "width": 200,
  "height": 50,
  "imageUrl": "https://oss.example.com/sku/SP001-RED-S.jpg"
}
```

**响应 data**：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | SKU ID |
| skuCode | string | 生成的 SKU 编码 |

**错误码**：20001、20002、20004

**业务规则**：
1. `SPU + 颜色 + 尺码` 组合唯一
2. 条形码全局唯一，不可与其他 SKU 冲突
3. 创建后默认状态为"启用"

## 十三、接口调用时序示例


## 十四、非功能约定

| 项 | 要求 |
|---|---|
| 查询响应 | ≤ 1 秒（单表分页查询） |
| 导入接口 | ≤ 30 秒（5000 行） |
| 导出接口 | ≤ 30 秒（10 万行，异步 + 进度查询） |
| 幂等性 | 创建类接口支持 `Idempotency-Key` 请求头防重复提交 |
| 并发 | 编码生成、批量创建需加锁保证唯一性 |
| 日志 | 所有写操作记录操作日志，敏感字段（密码）脱敏 |
