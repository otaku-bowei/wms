## 一、通用约定

沿用 R1 接口文档约定：

- 基础路径：`https://{host}/api/v1`
- 认证：`Authorization: Bearer {token}`
- 统一响应体：`{code, message, data, timestamp, traceId}`
- 分页：`{list, total, pageNum, pageSize, pages}`

**新增错误码**：

| 错误码 | 常量 | 说明 |
|---|---|---|
| 21001 | INBOUND_NO_EXISTS | 入库单号已存在 |
| 21002 | INBOUND_NOT_FOUND | 入库单不存在 |
| 21003 | INBOUND_STATUS_INVALID | 入库单状态不允许该操作 |
| 21004 | INBOUND_QTY_EXCEED | 上架数量超过待上架数量 |
| 22001 | STOCK_NOT_FOUND | 库存记录不存在 |
| 22002 | STOCK_NOT_ENOUGH | 可用库存不足 |
| 23001 | ADJUST_NOT_FOUND | 调整单不存在 |
| 23002 | ADJUST_STATUS_INVALID | 调整单状态不允许审批 |

## 三、入库预约单接口

### 3.1 分页查询入库单

```
GET /api/v1/inbound/orders
```

**权限**：`inbound:view`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| inboundNo | String | 否 | 入库单号（模糊） |
| warehouseId | Long | 否 | 仓库 |
| inboundType | String | 否 | PURCHASE / RETURN / TRANSFER |
| supplierId | Long | 否 | 供应商 |
| status | String | 否 | 状态 |
| expectedStart / expectedEnd | LocalDateTime | 否 | 预计到货时间范围 |
| pageNum / pageSize | Integer | 否 | 分页 |

**响应 data**：`PageResult<InboundOrderVO>`

---

### 3.2 创建入库预约单

```
POST /api/v1/inbound/orders
```

**权限**：`inbound:create`

**请求体**：

```json
{
  "warehouseId": 1,
  "inboundType": "PURCHASE",
  "supplierId": 1,
  "expectedTime": "2026-10-10 10:00:00",
  "remark": "首批到货",
  "items": [
    { "skuId": 1, "planQty": 100, "batchNo": "B20261010" }
  ]
}
```

**业务校验**：

| 校验项 | 错误码 |
|---|---|
| 明细为空 | 21004 |
| 计划数量 ≤ 0 | 21005 |
| 仓库已停用 | 30002 |

**响应 data**：`Long`（入库单 ID）

---

### 3.3 查询入库单详情

```
GET /api/v1/inbound/orders/{id}
```

**权限**：`inbound:view`

**响应 data**：`InboundOrderVO`（含 items 明细）

---

### 3.4 修改入库预约单

```
PUT /api/v1/inbound/orders/{id}
```

**权限**：`inbound:edit`

**业务校验**：已到货（ARRIVED 及之后）不可修改

---

### 3.5 确认 / 取消入库单

```
PUT /api/v1/inbound/orders/{id}/status
```

**权限**：`inbound:edit`

**请求参数**：`status`（CONFIRMED / CANCELLED）

### 3.6 到货登记

```
POST /api/v1/inbound/orders/{id}/arrive
```

**权限**：`inbound:receive**

### 3.7 提交质检结果

```
POST /api/v1/inbound/orders/{id}/qc
```

**权限**：`inbound:receive**

### 3.8 查询入库单明细

```
GET /api/v1/inbound/orders/{id}/items
```

**权限**：`inbound:view**

## 四、上架任务接口

### 4.1 分页查询上架任务

```
GET /api/v1/inbound/putaway-tasks
```

**权限**：`putaway:view**

### 4.2 上架确认

```
POST /api/v1/inbound/putaway-tasks/{id}/confirm
```

**权限**：`putaway:execute**

**业务校验**：
| 校验项 | 错误码 |
|---|---|
| 库位锁定 / 维修中 | 40003 |
| 上架数量 > 待上架数量 | 21004 |

### 4.3 批量上架确认

```
POST /api/v1/inbound/putaway-tasks/batch-confirm
```

**权限**：`putaway:execute**

## 五、库存接口

| # | 方法 | HTTP | 路径 | 权限 |
|---|---|---|---|---|
| 1 | `page` | GET | `/api/v1/inventory/stocks` | inventory:view |
| 2 | `skuSummary` | GET | `/api/v1/inventory/stocks/sku/{skuId}` | inventory:view |
| 3 | `transactions` | GET | `/api/v1/inventory/transactions` | inventory:view |

### 5.1 分页查询库存

```
GET /api/v1/inventory/stocks
```

**请求参数**：warehouseId、zoneId、locationId、skuId、barcode、batchNo、status、keyword、分页

### 5.2 按 SKU 查询库存汇总

```
GET /api/v1/inventory/stocks/sku/{skuId}
```

**响应 data**：`StockSummaryVO` —— 总库存 / 可用 / 锁定 / 冻结 / 分布仓库数

### 5.3 分页查询库存流水

```
GET /api/v1/inventory/transactions
```

**请求参数**：skuId、warehouseId、locationId、transactionType、relatedNo、时间范围、分页
